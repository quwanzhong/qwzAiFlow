# 数据结构与算法

## 时间复杂度速查(平均 / 最坏 / 稳定性)

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | ✔ | 加提前退出标志,基本有序可到 O(n) |
| 选择 | O(n²) | O(n²) | O(1) | ✘ | 比较次数固定 n(n-1)/2 |
| 插入 | O(n²) | O(n²) | O(1) | ✔ | 基本有序时接近 O(n),小规模最快之一 |
| 希尔 | ~O(n^1.3) | O(n²) | O(1) | ✘ | 插入的分组改进 |
| 快排 | O(nlogn) | O(n²)(已有序) | O(logn) | ✘ | 轴值选取是关键;最坏发生在基本有序 |
| 归并 | O(nlogn) | O(nlogn) | O(n) | ✔ | 稳定的 nlogn,外部排序基础 |
| 堆排 | O(nlogn) | O(nlogn) | O(1) | ✘ | 建 O(n),取最值 O(logn);Top-K 常用 |
| 基数 | O(d(n+r)) | 同左 | O(n+r) | ✔ | d 位数,r 基数 |

易错:仅 冒泡/插入/归并/基数 稳定;"基本有序的序列选哪种排序"→ 插入或冒泡;
"取前 K 大"→ 小顶堆 O(nlogK)。

## 二叉树

- 性质:i 层最多 2^(i-1) 个节点;h 层二叉树最多 2^h - 1;
  **叶子数 n₀ = 度为 2 的节点数 + 1**(n₀ = n₂ + 1,常考)。
- n 个节点完全二叉树高度:⌈log₂(n+1)⌉。
- 遍历组合还原:中序 + (前序或后序) 可唯一还原;**前序+后序不能**。
- BST:中序遍历得升序序列。AVL:左右子树高度差 ≤1,失衡用 LL/RR/LR/RL 旋转。
- 哈夫曼树:带权路径长度 WPL 最小;**n 个叶子共 2n-1 个节点,无度为 1 的节点**。
- B/B+ 树:B+ 树数据全在叶子层且叶子成链表 —— 为什么数据库索引用它(矮胖、
  范围查询、叶子链表遍历)。

## 图

| 存储 | 空间 | 适用 |
|---|---|---|
| 邻接矩阵 | O(n²) | 稠密图;判断任意两点邻接 O(1) |
| 邻接表 | O(n+e) | 稀疏图 |

- 遍历:BFS 用队列(求无权最短路),DFS 用栈/递归(求连通分量、拓扑序)。
- 最短路:Dijkstra(无负权,O(n²)),Floyd(全源,三重循环 O(n³),可处理负权边)。
- 最小生成树:Prim(稠密图,从一个点长出)、Kruskal(稀疏图,边排序+并查集)。
- 拓扑排序:AOV 网去掉入度 0 顶点;**环检测 = 拓扑排不完**。
- AOE 关键路径:关键路径 = 最长路径 = 工程最短工期;活动的最早/最迟开始 = 
  事件时间推算,总时差为 0 的活动在关键路径上。

## 算法策略辨识

| 策略 | 特征 | 典型 |
|---|---|---|
| 分治 | 子问题独立,合并解 | 二分查找、归并、快速排序 |
| 贪心 | 每步局部最优且**可证明**全局最优 | Prim/Kruskal、Dijkstra、Huffman、活动选择 |
| 动态规划 | 子问题重叠 + 最优子结构,要填表 | 最长公共子序列、背包、最短路(带负权场景) |
| 回溯 | 试错 + 剪枝,走不通退回 | 八皇后、子集生成、迷宫 |
| 分支限界 | 回溯 + 界函数剪枝,BFS 式展开 | TSP、0-1 背包的精确求解 |

辨析口诀:**子问题独立→分治;重叠→DP;每步确定不回头→贪心;要回头→回溯**。
贪心不保证全局最优(除非可证明),DP 用空间换时间。
