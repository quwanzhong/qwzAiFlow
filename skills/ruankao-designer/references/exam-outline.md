# 软件设计师(中级)考试结构与考点分布

> 软考中级资格,一年两考(上半年 5 月下旬、下半年 11 月上旬,以中国计算机技术职业
> 资格网当年通知为准)。**两科需同次考试都达到合格线**(通常各 45 分/满分 75)。

## 科目结构

| 科目 | 时段 | 时长 | 题型 | 满分 | 合格 |
|---|---|---|---|---|---|
| 基础知识 | 上午 | 150 分钟 | 75 道单选,每题 1 分 | 75 | 45 |
| 应用技术 | 下午 | 150 分钟 | 案例分析大题(见下) | 75 | 45 |

## 上午题考点分布(经验占比,按频次排序)

| 考点块 | 约占分 | 高频内容 |
|---|---|---|
| 软件工程 | 8~10 | 开发模型(瀑布/敏捷/螺旋)、需求分析、测试(白盒/黑盒、覆盖)、维护、CMM/CMMI、耦合内聚 |
| 数据结构与算法 | 7~9 | 二叉树性质与遍历、图(存储/遍历/最短路/拓扑)、排序比较、查找(二分/哈希)、时间复杂度 |
| 程序设计语言基础 | 5~7 | 编译/解释、文法与自动机、传值/传引用、正规式 |
| 面向对象与设计模式 | 6~8 | OO 基本概念、UML 图辨析、SOLID、23 种设计模式识别(与 design-patterns.md 配合) |
| 计算机组成与体系结构 | 5~6 | 浮点数表示、码制/校验(CRC/海明)、CPU 结构、指令流水线、可靠性(串并联)、存储层次 |
| 操作系统 | 5~6 | 进程状态转换、PV 操作、死锁、页式/段式存储(虚实地址)、磁盘调度、文件管理 |
| 数据库 | 5~6 | 关系代数、范式判定、E-R 模型、SQL、事务 ACID、并发控制 |
| 计算机网络 | 5~6 | OSI/TCP-IP 分层、IP 地址与子网划分、常用协议端口、传输层 |
| 信息安全 | 3~4 | 对称/非对称加密、数字签名与证书、攻击类型、防火墙 |
| 数学与经济管理 | 3~4 | 排列组合、线性规划、净现值/投资回收、图论应用(最小生成树) |
| 知识产权与标准化 | 2~3 | 著作权/专利权保护期、软件保护条例、侵权判定、标准代号 |
| 专业英语 | 5 | IT 领域短文填空(软件工程/新技术主题) |

## 下午题题型(5 组,第 5/6 题二选一,每题 15 分)

| 题号 | 考点 | 常见问法 |
|---|---|---|
| 试题一 | 数据流图(结构化分析) | 补实体/存储/数据流、找数据流错误、给加工说明 |
| 试题二 | 数据库设计 | 填 E-R 联系类型、转关系模式并标主外键、写 SQL(建表/查询) |
| 试题三 | UML(面向对象分析) | 用例图/类图/顺序图填空、识别设计模式类角色 |
| 试题四 | 算法分析与设计 | 给代码填 3~4 空、判断算法策略(分治/贪心/DP)、算复杂度 |
| 试题五/六 | 设计模式(C++/Java 二选一) | 按类图填代码空(类名、方法名、继承/组合关系) |

## 复习建议要点

- 下午题提分性价比高:题型固定,五类各刷 5~10 套真题即可形成模板化解法;
- 上午题靠广度:错题按上表考点块归类,哪块得分率低于 60% 回炉哪块;
- 真题是唯一权威题源:近 5~8 年真题至少完整刷一遍,模拟题只作补充;
- 背诵类硬骨头:知识产权年限、各加密体系特性、设计模式意图——做成卡片考前突击。
