# 计算机组成与体系结构

## 数据表示

- 原码/反码/补码:正数三者相同;负数反码 = 原码除符号位取反,
  **补码 = 反码 + 1**。补码表示范围比原码多一个负数:
  8 位补码 [-128, +127],原码 [-127, +127]。**0 在补码中唯一**。
- 定点/浮点:**浮点数 N = 尾数 × 基数^阶码**。规格化:尾数最高位为有效位
  (1/2 ≤ |尾数| < 1)。
  - IEEE754 单精度 32 位:1 符号 + 8 阶码(移码 127)+ 23 尾数(隐含 1.);
  - 运算步骤:对阶(**小阶向大阶对齐**,尾数右移)→ 尾数运算 → 规格化 → 舍入 → 溢出判断。
- 溢出判断:双符号位 01 正溢出、10 负溢出;或最高数值位进位 ⊕ 符号位进位。
- 校验码:
  - 奇偶校验:可检奇数位错,**不能纠错**;
  - **海明码:2^k ≥ n + k + 1(数据 n 位所需校验位 k)**;校验位放在 2^i 位置,
    可检 2 位错、纠 1 位错;
  - CRC 循环冗余:**模 2 除法(异或)**,生成多项式 R 位 → 附加 R−1 位;
    只检错不纠错(链路层常用)。

## CPU 与指令

- CPU 组成:运算器(ALU、累加器、状态寄存器)+ 控制器(PC、IR、ID、
  时序、微操作信号)。**PC 存下一条指令地址,IR 存当前指令**。
- 寻址方式速度:立即寻址最快(操作数在指令里),寄存器寻址次之,
  间接寻址最慢(多次访存)。寻址方式种类越多、指令越复杂 → CISC;精简固定长度 → RISC
  (RISC:指令定长、Load/Store 访存、大量寄存器、适合流水线)。
- 流水线(必考计算):
  - 执行时间 = **1 条指令完整时间 + (n−1) × 周期(最慢一段)**
  - 吞吐率 = n / 流水线执行时间;最大吞吐率 = 1 / 周期
  - 加速比 = 不用流水线时间 / 流水线时间
  - 冲突:资源冲突(停顿)、数据相关(旁路/定向)、控制相关(分支预测)。

## 存储层次

金字塔:寄存器 → Cache(L1/L2/L3)→ 主存 → 外存,越下越慢越大越便宜。
依据:**局部性原理(时间局部性 + 空间局部性)**。

- Cache 映射:直接(主存块号 mod 行数,冲突高)、全相联(任意放,查得慢)、
  组相联(折中,最常用)。命中率 h:平均访问时间 = h×tc + (1−h)×(tc+tm)。
- 主存编址计算题:**按字节编址,`地址区间差 + 1` = 总单元数;总容量 ÷ 单片容量
  = 芯片数**。例:A0000H~CFFFFH 共 0x30000 = 192K 单元。

## 可靠性与校验计算

- 串联系统(一个坏全坏):**R = R1 × R2 × … × Rn**
- 并联系统(全坏才坏):**R = 1 − (1−R1)(1−R2)…(1−Rn)**
- 混合:先并后串按公式嵌套。MTBF = 1/λ;MTTR 修复时间。

## 其他高频

- 总线:数据线宽度决定一次传多少位;地址线条数决定寻址空间
  (32 位地址线 = 4GB 空间)。
- 输入输出:程序查询(CPU 忙等)→ 中断(通知式)**中断向量 = 中断服务程序入口**
  → DMA(成块传输不经 CPU,周期挪用)→ 通道。
- 校验场景选择:内存用海明(可纠 1 位),链路层用 CRC,简单状态用奇偶。
