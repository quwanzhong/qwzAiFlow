# 计算机网络与信息安全

## 分层模型

| OSI 七层 | TCP/IP 四层 | 代表协议/设备 |
|---|---|---|
| 应用/表示/会话 | 应用 | HTTP(S)、FTP、SMTP/POP3/IMAP、DNS、DHCP、Telnet/SSH |
| 传输 | 传输 | TCP、UDP — 网关/防火墙 |
| 网络 | 网络 | IP、ICMP、ARP、路由协议 — 路由器 |
| 数据链路 | 网络接口 | 以太网、PPP、VLAN — 交换机/网桥 |
| 物理 | | 中继器/集线器 |

设备层级:**集线器(物理,广播)→ 交换机(链路,按 MAC)→ 路由器(网络,按 IP)**。
ARP:IP → MAC;DNS:域名 → IP(UDP 53,区域传送用 TCP);DHCP:自动分配
IP(UDP,Discover→Offer→Request→ACK)。

## TCP vs UDP

| 维度 | TCP | UDP |
|---|---|---|
| 连接 | 面向连接(三次握手) | 无连接 |
| 可靠 | 确认重传、有序 | 尽力而为 |
| 流量/拥塞控制 | 有(滑动窗口、慢启动) | 无 |
| 场景 | 网页、文件、邮件 | 直播、DNS、游戏、心跳 |

- **三次握手**:SYN → SYN+ACK → ACK。为什么三次:双方各确认"我能发你能收",
  防历史连接请求误建。
- **四次挥手**:FIN → ACK → FIN → ACK;**TIME_WAIT 等 2MSL**:确保最后 ACK
  达到、旧报文消亡。 CLOSE_WAIT 堆积 = 对端关了你没关(代码漏 close)。
- 滑动窗口:流量控制;慢启动→拥塞避免→快重传/快恢复:拥塞控制。

## HTTP / HTTPS

- HTTP 方法语义:GET 幂等取、POST 建、PUT 全量替换、DELETE 删;
  状态码:2 成功 / 3 重定向(301 永久、302 临时、304 缓存)/ 4 客户端错
  (401 未认证、403 禁止、404 不存在、429 限流)/ 5 服务端错(500、502 网关、504 超时)。
- 1.1 长连接 + 管道化;2 多路复用 + 头压缩 + 二进制分帧;3 基于 QUIC/UDP。
- HTTPS = HTTP + **TLS**;握手:协商套件 → 服务器证书(**CA 私钥签名**,
  客户端用内置 CA 公钥验签)→ 非对称算法交换密钥材料 → 会话对称密钥加密通信。
  口诀:**非对称换密钥,对称传数据**。

## IP 与子网划分(计算题套路)

- IP = 网络位 + 主机位;掩码 1 的个数 = 网络位。
- 划分五步:① 需要几个子网/每网多少主机 → ② 主机位 m 满足 2^m − 2 ≥ 需求
  (减网络地址与广播地址)→ ③ 掩码 = 32 − m → ④ 各子网按块大小
  (2^m)排 → ⑤ 可用范围 = 网络地址+1 ~ 广播地址−1。
- 例:192.168.1.0/26 → 块大小 64,四个子网 .0/.64/.128/.192,
  每个 62 台可用主机。
- 私有地址段:10/8、172.16/12、192.168/16;127/8 回环;169.254/16 APIPA
  (DHCP 失败自配,排障先看这个)。

## 信息安全

| 体系 | 特性 | 代表 | 用途 |
|---|---|---|---|
| 对称加密 | 快;密钥分发难,双方共享同一钥 | DES、3DES、AES、RC4、SM4 | 大批量数据加密 |
| 非对称加密 | 慢;公钥加密私钥解 | RSA、ECC、SM2 | 密钥交换、签名 |
| 摘要 | 单向、定长、抗碰 | MD5(已破)、SHA-1(已弱)、SHA-2、SM3 | 完整性 |

- **数字签名 = 发送方用自己的私钥对摘要加密** → 验证:发送方公钥解开比对。
  作用:身份认证 + 不可否认 + 完整性(与加密方向相反:签名用私钥,加密用对方公钥)。
- 数字证书:CA 用 CA 私钥签"公钥 + 身份信息"。
- 攻击速查:重放(时间戳/一次性 nonce 防御)、中间人(证书校验)、
  SQL 注入(参数化查询)、XSS(输出转义)、CSRF(Token)、DDoS(流量清洗)。
- 防火墙:包过滤(网络层,快,粗)、应用网关(细,慢)、状态检测(折中);
  DMZ:对外服务放 DMZ 区,内外网互访受限。
- 密钥管理:Kerberos(票证防重放);PKI = CA + 证书 + 密钥管理。
