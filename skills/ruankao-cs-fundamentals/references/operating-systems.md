# 操作系统

## 进程 vs 线程(高频对比)

| 维度 | 进程 | 线程 |
|---|---|---|
| 定位 | 资源分配单位 | CPU 调度单位 |
| 地址空间 | 独立 | 共享所属进程的地址空间与资源 |
| 切换开销 | 大(换页表、刷新 TLB) | 小 |
| 通信 | 管道/消息队列/共享内存/信号量/Socket | 直接读写共享变量(需同步) |
| 崩溃影响 | 隔离,互不拖垮 | 一个线程崩溃可能拖垮整个进程 |

工程结论:要隔离与稳定用多进程,要轻量共享数据用多线程;共享必加锁。

## 进程状态转换

三态:就绪 →(被调度)运行 →(时间片到)就绪;运行 →(等资源)阻塞 →
(资源就绪)就绪。**阻塞态不能直接转运行,运行态不能直接转阻塞的对立面**
—— 判断转换图正误就看这两条。

五态(加 创建/终止)、挂起态:内存不足时进程被换出 → 就绪挂起/阻塞挂起。

## 调度算法

| 算法 | 特点 | 缺陷 |
|---|---|---|
| FCFS 先来先服务 | 简单公平 | 长作业阻塞短作业(护航效应) |
| SJF 短作业优先 | 平均等待时间最短 | 长作业饥饿 |
| 优先级 | 分级响应 | 低优先级饥饿 → 老化(aging)解决 |
| 时间片轮转 | 交互响应好 | 片太小切换开销大,太大退化 FCFS |
| 多级反馈队列 | 兼顾交互与吞吐,无需预知时长 | 实现复杂 |

周转时间 = 完成时刻 − 到达时刻;带权周转 = 周转 / 运行。

## 死锁

四个必要条件(缺一不可,预防=破坏其中之一):**互斥、持有并等待、不可剥夺、
环路等待**。

- 银行家算法:避免策略,找安全序列。
- 工程排查口诀:多把锁 → 固定全局加锁顺序(破坏环路等待)→ 消灭死锁;
  或一次申请全部资源(破坏持有并等待)、支持超时与剥夺。
- 哲学家进餐解法:最多 4 人同时拿筷 / 一次性拿两支 / 奇偶号顺序相反。

## PV 操作 / 信号量

- `P(S)`:S<0 则阻塞;`V(S)`:唤醒一个等待者。S 的负值 = 等待的进程数。
- **互斥**:信号量初值 1,临界区前后 P/V(同一信号量)。
- **同步**:前操作 V(s),后操作 P(s),初值 0 —— "先做 A 再做 B" 就在 B 前 P。
- 生产者-消费者:互斥 mutex=1,同步 empty=n、full=0;
  **P 顺序不能错:先同步(empty/full)后互斥(mutex),否则死锁**。
- 读者-写者:读者计数器 + 写者优先/公平变体。

## 内存管理

- 页式:等大小物理划分,有内部碎片无外部碎片;**虚实地址换算:页号 =
  逻辑地址 ÷ 页大小(取整),页内偏移 = 余数;查页表得物理块号,物理地址 =
  块号 × 页大小 + 偏移**。快表(TLB)命中则省一次访存;访问一次数据,
  无快表要 2 次访存,有快表 1 次(命中率 h,平均 = h×1 + (1−h)×2 次访存)。
- 段式:按逻辑意义划分(代码段/数据段),方便共享保护,有外部碎片。
- 页面置换:
  - OPT 最优(向后看,理论基准)、FIFO(可能 **Belady 异常**:页框增多缺页反而增)、
  - **LRU(向前看,最常使用)—— FIFO 和 LRU 都向前/向后看,判断题考这个区别**,
  - Clock/NRU:循环 + 访问位。
- 虚存:请求分页 = 页式 + 缺页中断 + 置换;工作集 = 近期活跃页集合,
  防抖动的最低常驻页数。

## 磁盘调度与存储

| 算法 | 规则 | 特点 |
|---|---|---|
| FCFS | 按请求顺序 | 公平,差 |
| SSTF | 最近优先 | 吞吐高,饥饿 |
| SCAN 电梯 | 单向扫到头再回 | 无饥饿 |
| C-SCAN | 单向扫描,到头直接回起点再扫 | 响应更均匀 |

磁盘存取时间 = 寻道时间 + 旋转延迟(半圈)+ 传输时间。
文件物理结构:连续(随机快,难扩)、链接(无随机)、**索引(UNIX inode:
直接块 + 一级/二级/三级间接块,考"最大文件大小"计算题)**。
